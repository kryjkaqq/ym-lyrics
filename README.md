# YM Lyrics

Мод для десктопной **Яндекс Музыки** (Windows): полноэкранный режим с синхронным текстом песни и анимацией слов,
визуализатор, который ловит бит, и тема всего приложения в цветах текущей обложки.

## Установка (2 клика)

1. Скачай `ym-lyrics-vX.Y.Z.zip` со страницы [Releases](../../releases/latest) и распакуй куда угодно.
2. Запусти **`Установить.bat`**.

Установщик сам закроет Яндекс Музыку, сделает резервную копию, встроит мод и снова её откроет.
Если на компьютере нет Node.js, он один раз скачает портативную версию (~30 МБ) в `%LOCALAPPDATA%\ym-lyrics`.
Ничего собирать и ставить вручную не нужно.

В приложении включи трек и нажми **L** (или кнопку «Текст»). Настройки — кнопка ⚙.

- После **автообновления** Яндекс Музыки мод слетает: просто запусти `Установить.bat` ещё раз.
- **Удаление**: `Удалить.bat` вернёт оригинальные файлы из резервной копии.
- Windows может предупредить о файле из интернета: это нормально для `.bat` без цифровой подписи.

> Модификация клиента не одобрена Яндексом, используй на свой риск.

## Что умеет

- **Синхронный текст** с анимацией слов: заливка, прыжок, свечение, появление. Клик по строке — перемотка к ней.
  Нет текста — крупная обложка по центру со спектром.
- **Визуализатор**: кольцо спектра по контуру обложки, полосы, волны, аура, круги от обложки, звёздный тоннель,
  пиксельный эквалайзер. Бит ловится по звуку (бочка, малый, хэты отдельно), темп сверяется с базой Deezer;
  на бит — мягкий толчок и свечение с акцентом на сильной доле.
- **Тема всего приложения**: фон окна из размытой обложки, стеклянные панели, акцентный цвет из обложки
  вместо жёлтого (только для тёмной темы Яндекс Музыки, отключается в ⚙).
- **Плеер**: перемотка перетаскиванием с подсказкой времени, лайк/дизлайк (сохраняются в аккаунт),
  полноэкранный режим и кнопка «свернуть».
- **Настройки**: 16 шрифтов с кириллицей (широкие, с засечками, тонкие, пиксельные), размер, выравнивание, толщина,
  цвет акцента, сила толчка/свечения/спектра, затемнение фона, частицы, сдвиг таймингов, 30/60 кадров.

## Управление

| Клавиша / действие | Что делает |
|---|---|
| `L` | открыть / закрыть текст |
| `F` / кнопка ⛶ | во весь экран / обратно |
| `Пробел` | пауза / воспроизведение |
| `Esc` | закрыть |
| клик по строке | перемотать к ней |
| колесо мыши | прокрутить текст (через 2.5 с вернётся к текущей строке) |
| перетаскивание по полосе | перемотка |
| ♡ / 👎 | лайк / дизлайк |

## Откуда берутся тексты

Тексты не хранятся в моде, а загружаются при воспроизведении:

1. **Яндекс Музыка**: если приложение само загрузило синхронный текст, мод использует его.
2. **[LRCLIB](https://lrclib.net)**: открытая база синхронизированных текстов (точный запрос, затем поиск по очищенному
   названию и транслиту, совпадение по длительности ±4 с).
3. **NetEase Cloud Music**: большой каталог, у части треков есть тайминги по каждому слову.
4. **lyrics.ovh**: запасной вариант, только текст без таймингов.

Результаты кэшируются, «не найдено» хранится сутки (кнопка «Поискать ещё раз» сбрасывает кэш).

## Как это устроено

- Установщик распаковывает `resources/app.asar` и добавляет в него скрипт мода (первым в `<head>` всех страниц),
  мост в `preload.js` и обработчики в `index.js`: сетевые GET-запросы только к источникам текстов и Deezer,
  полноэкранный режим, сворачивание окна, системный звук для визуализатора, лог диагностики.
- В приложении включён фьюз Electron `EmbeddedAsarIntegrityValidation`: хеш заголовка asar зашит в exe, поэтому
  установщик заменяет его на хеш нового архива (проверка остаётся включённой). Перед этим делаются резервные копии
  `app.asar.ym-lyrics.bak` и `Яндекс Музыка.exe.ym-lyrics.bak`. Подпись exe после этого недействительна.
- Состояние плеера мод берёт без доступа к внутренностям приложения: метаданные из `navigator.mediaSession`,
  позицию из `<audio>`, управление через обработчики `mediaSession` и горячие клавиши самого приложения.
- Звук для визуализатора берётся из графа Web Audio приложения, `audio.captureStream()` или системного звука —
  из первого источника, где он реально есть.
- Тема приложения переопределяет CSS-переменные темы Яндекс Музыки (`--ym-*`), разметку не трогает.
- Диагностика пишется в `%APPDATA%\YandexMusic\ym-lyrics.log`.

## Разработка

```
npm install
npm test                        # парсер LRC, тайминги, поиск текстов, анализ бита
node build.mjs                  # → dist/
node patcher/patch.mjs install  # встроить в установленную Яндекс Музыку (status / restore)
node scripts/release.mjs        # → release/ym-lyrics-vX.Y.Z.zip
node scripts/fetch-fonts.mjs    # обновить шрифты из Google Fonts
```
